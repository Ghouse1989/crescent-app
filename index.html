Saving your data

Where your records are saved: in this web browser, on this computer. They are not sent anywhere, and you do not need internet to use this file.

To keep your records safe:

  • Open this file in a normal window. Do not use a private or incognito window. Records added there are deleted when you close that window.
  • Use the same browser every time. Chrome, Edge and Firefox each keep their own records.
  • Do not clear your browser history or site data. That deletes your records and photos.
  • Photos are saved in this browser too. ID photos are private, so keep backup files safe.
  • Keep the file in the same folder. Moving it may hide your records.
  • Turn on automatic daily backup in the box above, or make a backup every week.
  • Make a backup every week. Use Download backup below, then save the file in email, Google Drive or on a USB stick.

If your records disappear: open this file in the same browser, go to Restore data below, choose your latest backup, then tap Restore data and tap it again to confirm.

Automatic daily backup

The backup is saved as a file in your downloads at the time you choose, using this device's clock. The app must be open at that time. If it was closed, the backup is saved as soon as you open the app. On a phone, if the file does not download, tap Download backup instead.

Backup & restore

Download a backup regularly. See Saving your data at the top of Settings.

Restoring replaces current records. Backups from the old app work here too.
